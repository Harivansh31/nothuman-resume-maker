# NotHuman — Premium Resume Builder

A responsive browser-based resume builder with a dark, premium workspace and an A4 resume preview.

## Features in this version
- Edit resume details from form fields or directly on the preview
- Multiple resume templates and accent-color controls
- Section management and formatting controls
- Browser-local autosave
- Import/export project data as JSON
- Print or save the resume as PDF using the browser print dialog
- Responsive layout

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build step or package installation is required.

## Deployment
This is a static website and can be hosted on GitHub Pages, Netlify, or Vercel. Keep `index.html` and the `assets` folder together.

## Notes
- Resume data is saved in the current browser's local storage. It is not synced to an account or cloud.
- PDF export uses the browser's print dialog; choose **Save as PDF** and A4 paper size.
- This version does not include a live AI service/API integration.
